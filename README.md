# 📱 App Nutri Mais
***
Este é um aplicativo de nutrição desenvolvido para apresentar exercícios físicos e sugestões de alimentação de forma simples e objetiva. Seu principal objetivo é informar e orientar o usuário sobre hábitos mais saudáveis.

# 🛠️ Ferramentas Utilizadas
***
- App Inventor 
- Figma

# 🚀 Como acessar o aplicativo
***
- Faça o download da versão APK do projeto.
- Instale o aplicativo no seu dispositivo.
- Pronto! Agora é só explorar os conteúdos de nutrição e exercícios.
